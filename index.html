Anthropic API Key

Get at console.anthropic.com → API Keys → Create Key. ~$0.01 per reply generation.

Notion Integration Token

Get at notion.so/my-integrations → New integration → copy token. Make sure to connect it to your database.

Notion Database ID
How it works: This app is hosted on Netlify. Replies and comments call the Anthropic API directly from your browser. Insights, Write Post, and Log Post go through Netlify server functions that talk to Notion — this fixes the CORS restriction. Your keys are saved locally in your browser.
